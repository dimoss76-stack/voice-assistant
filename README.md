# Голосовой Помощник для незрячих (Voice Assistant)

**Голосовой Помощник** — это Android-приложение, созданное для помощи незрячим и слабовидящим людям в управлении телефоном с помощью голоса. Программа позволяет совершать звонки, узнавать время и дату, а также отвечать на входящие звонки, не прикасаясь к экрану.

## 🎯 Основные возможности

*   **Голосовая активация:** Скажите «Слушай», чтобы начать.
*   **Звонки:** «Слушай, позвони» → назовите имя контакта → подтвердите «да».
*   **Входящие звонки:** Программа озвучивает имя звонящего и ждёт «да» или «нет». Также есть большие кнопки на экране (для зрячих помощников).
*   **Время и дата:** «Слушай, время» или «Слушай, дата».
*   **Список контактов:** «Слушай, контакты» — программа перечислит все контакты по алфавиту.
*   **Завершение звонка:** Во время разговора скажите «Завершить этот звонок».
*   **Настройки:** Можно изменить ключевые слова, включить/отключить команду выключения и выбрать расположение кнопок при звонке.

## 📱 Как установить

1.  Скачайте последний APK-файл со страницы [Releases](https://github.com/dimoss76-stack/voice-assistant/releases).
2.  Установите его на телефон (разрешите установку из неизвестных источников, если потребуется).
3.  При первом запуске предоставьте все запрашиваемые разрешения (микрофон, контакты, телефон).
4.  **Важно:** Отключите оптимизацию батареи для этого приложения (Настройки → Приложения → Голосовой Помощник → Батарея → «Без ограничений»). Это нужно, чтобы программа работала в фоне.

## 🛠 Технические детали

*   **Платформа:** Android (minSdk 21, targetSdk 34).
*   **Распознавание речи:** [Vosk](https://alphacephei.com/vosk/) (офлайн, модель `vosk-model-small-ru-0.22`).
*   **Синтез речи:** Android TextToSpeech (TTS).
*   **Звонки:** `TelecomManager` (обход ограничений Android 14).
*   **Сборка:** GitHub Actions.
