# Политика конфиденциальности приложения «Голосовой Помощник»

**Дата последнего обновления:** 22 октября 2026 г.

## 1. Общие положения

Настоящая Политика конфиденциальности описывает, как приложение **«Голосовой Помощник»** (далее — Приложение) обрабатывает и защищает информацию пользователя.

Приложение создано для помощи незрячим и слабовидящим людям в управлении телефоном с помощью голоса.

## 2. Какие данные использует Приложение

Приложение **НЕ собирает, НЕ передаёт и НЕ хранит** ваши персональные данные на сторонних серверах.

Для работы Приложению требуются следующие разрешения:

*   **Микрофон (RECORD_AUDIO):** для распознавания голосовых команд. Аудио обрабатывается **локально** на устройстве с помощью офлайн-модели Vosk. Аудио **не передаётся** в интернет.
*   **Контакты (READ_CONTACTS):** для поиска контактов по имени и совершения звонков. Данные контактов **не покидают** устройство.
*   **Телефон (READ_PHONE_STATE, CALL_PHONE, ANSWER_PHONE_CALLS):** для обработки входящих звонков и совершения исходящих звонков.
*   **Уведомления (POST_NOTIFICATIONS):** для отображения статуса работы Приложения.

## 3. Передача данных третьим лицам

Приложение **не передаёт** ваши данные третьим лицам. Вся обработка происходит **локально** на вашем устройстве.

## 4. Хранение данных

Настройки Приложения (ключевые слова, выбор кнопок) хранятся **локально** на устройстве в защищённом хранилище Android (SharedPreferences). Они **не передаются** в интернет.

## 5. Безопасность

Приложение не использует интернет для передачи голосовых данных. Распознавание речи происходит офлайн, что гарантирует конфиденциальность ваших разговоров.
